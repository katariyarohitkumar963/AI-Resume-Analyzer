# AI Resume Analyzer

A CSE Diploma College Project developed using Python and Flask.

## Features
- Upload PDF and DOCX resumes
- Extract resume text
- Detect skills using keyword matching
- Identify email and phone details
- Generate resume score
- Display improvement suggestions
- Download PDF analysis report

## Technologies Used
- Python
- Flask
- HTML
- pypdf
- python-docx
- ReportLab

## Project Structure
- app.py
- requirements.txt
- templates/
  - index.html
  - result.html

## How to Run
1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open http://127.0.0.1:5000

## Analysis Method
The project uses rule-based keyword matching. It is not a trained machine learning model.
